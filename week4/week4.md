## 2. 개선 인터페이스 설계

### 2.1 사용자 및 관찰 목표

3D 조작에 익숙하지 않은 시설 점검자가 여섯 장치의 정보를 쉽게 확인하고, 두 구조의 차이를 정확하게 비교할 수 있도록 한다.

- **조작 부담 감소:** 반복적인 회전 없이 원하는 관찰 지점으로 이동
- **정확한 구조 비교:** 전면·측면 직교 뷰를 통해 높이, 폭, 돌출 정도 확인

### 2.2 설계 대안 비교

**대안 A — 관찰 지점 선택형**

P1~P6의 관찰 지점을 버튼으로 제공하고, 선택 시 해당 장치를 관찰하기 좋은 위치로 카메라가 자동 이동하는 방식이다.

- 장점: 반복적인 회전과 이동을 줄일 수 있다.
- 단점: 구조의 높이와 폭을 정확하게 비교하기 위한 기능이 별도로 필요하다.

**대안 B — 다중 시점 비교형**

전체·전면·측면·상단 화면을 동시에 제공하여 여러 방향에서 구조물을 관찰하는 방식이다.

- 장점: 서로 다른 방향에서 구조물을 비교할 수 있다.
- 단점: 화면이 분할되어 작은 명판을 읽기 어려울 수 있다.

### 2.3 최종 선택

대안 A의 관찰 지점 선택 방식을 기본으로 하고, 대안 B의 전면·측면 직교 뷰 기능을 결합하기로 하였다.

이를 통해 P1~P6에서는 버튼 클릭만으로 원하는 장치를 관찰하고, O1·O2에서는 정확한 방향과 동일한 배율에서 구조를 비교할 수 있도록 설계하였다. 또한 현재 관찰 지점을 표시하고 전체 보기 버튼을 제공하여 상세 관찰 후 전체 구조로 복귀할 수 있도록 한다.

### 4.2 카메라 및 투영 설계

**① P1~P6 관찰 카메라**

명판의 실제 위치(position)를 카메라의 target 및 회전 중심으로 설정하였다. 명판 방향(yaw)을 기준으로 앞면 방향을 계산하고, 해당 방향으로 관찰 거리만큼 떨어진 곳에 eye를 배치하였다.

관찰 거리는 명판의 크기, FOV 및 화면 비율(aspect)을 고려하여 결정하였다. 상세 보기에서는 명판을 크게 표시하고, 주변 보기에서는 해당 장치와 주변 구조를 함께 확인하도록 하였다.

**② O1·O2 직교 비교 카메라**

| 항목 | O1 전면 비교 | O2 오른쪽 측면 비교 |
|---|---|---|
| 카메라 방향 | +z → −z | +x → −x |
| up | +y | +y |
| 화면 가로축 | x | z (+z가 왼쪽) |
| 화면 세로축 | y | y |
| 투영 방식 | 직교 | 직교 |
| 비교 대상 | 패널 상단 높이와 폭 | 장치 돌출 정도 |

원근 투영은 거리에 따라 물체 크기가 달라 보이므로 구조 비교에는 직교 투영을 적용하였다. 두 비교 대상을 동일한 화면과 배율로 표시하고, 0.5m 격자 및 O2의 z=0 기준선을 제공하였다.

**③ 미니맵 카메라**

시설 경계(bounds)의 중심을 target으로 설정하고, 중심에서 `[22, 30, 28]`만큼 떨어진 위치에 eye를 배치하였다.

시설 경계의 8개 모서리를 카메라 축으로 투영하여 전체 구조가 들어오도록 범위를 계산하였다. 선택한 명판의 3D 좌표는 미니맵의 뷰·투영 행렬을 이용해 화면 좌표로 변환하여 위치 마커를 표시하였다.

미니맵은 메인 카메라와 독립적인 고정 직교 시점을 유지한다.

### 4.3 입력 및 화면 처리

기존 트랙볼 회전, Shift+드래그 및 오른쪽 드래그를 통한 평행 이동, 휠 확대·축소 기능을 유지하였다.

추가된 지점 선택 버튼으로 자동 카메라 이동이 가능하며, Home 키 또는 전체 보기 버튼으로 초기 시점에 복귀할 수 있다.

화면 크기가 변경되면 각 뷰의 aspect를 별도로 계산하여 왜곡을 방지하였다. 또한 선택한 명판에는 글자를 가리지 않는 강조 테두리를 표시하였다.

### 4.5 대표 코드

**① 관찰 지점 자동 이동 (`d04-inspection-student.js`)**

```javascript
function pointView(){
  const p=selected,aspect=mainAspect();
  const height=detail
    ? Math.max(p.size[1]/.48,p.size[0]/(aspect*.58))
    : Math.max(2.2,p.size[1]*3,p.size[0]*1.8/aspect);

  s.target=[...p.position];
  s.distance=Math.max(.45,height/(2*Math.tan(s.fov*Math.PI/360)));
  s.rotation=[0,Math.sin(p.yaw/2),0,Math.cos(p.yaw/2)];
}
```

선택한 명판의 위치를 카메라의 target과 회전 중심으로 설정하였다. 명판의 크기, FOV 및 화면 비율을 고려하여 관찰 거리를 계산하고, yaw를 이용해 명판 정면을 바라보도록 하였다.

**② 원근·직교 투영 (`d04-inspection-viewer.js`)**

```javascript
M.lookAt(view,camera.eye,camera.target,camera.up||[0,1,0]);

if(camera.orthographic){
  const half=camera.halfHeight||8;
  M.ortho(projection,-half*w/h,half*w/h,-half,half,
          camera.near||.02,camera.far||180);
}
else
  M.perspective(projection,
                (camera.fov||controls.state.fov)*Math.PI/180,
                w/h,camera.near||.02,camera.far||180);
```

카메라의 eye, target, up을 이용해 관찰 방향을 설정하였다. 일반 장치 관찰에는 원근 투영을, O1·O2 구조 비교에는 직교 투영을 적용하였다. 화면 비율(w/h)을 반영하여 창 크기가 변경되어도 모델이 왜곡되지 않도록 하였다.

**③ 미니맵 카메라 (`d04-inspection-student.js`)**

```javascript
const mapTarget=model.bounds.min.map(
  (x,i)=>(x+model.bounds.max[i])/2
);

const mapCamera={
  eye:mapTarget.map((x,i)=>x+[22,30,28][i]),
  target:mapTarget,
  up:[0,1,0],
  orthographic:true,
  near:.02,
  far:180
};
```

시설 전체의 중심을 target으로 설정하고, 일정한 방향에 eye를 배치하여 고정된 직교 미니맵을 구현하였다. 메인 카메라와 독립적으로 작동하므로 명판을 확대하거나 회전하더라도 전체 건물과 현재 관찰 위치를 확인할 수 있다.

## 5. 추가 수정 및 검증

### 5.1 추가 수정 내용

초기 개선 버전에서는 장치 선택 시 명판으로 자동 이동할 수 있었지만, 확대된 장치가 전체 건물의 어느 위치에 있는지 한눈에 파악하기 어려울 수 있다고 판단하였다.

이를 보완하기 위해 두 가지 기능을 추가하였다.

- **선택 장치 강조:** 선택한 명판에 3D 강조 테두리를 표시하였다.
- **전체 미니맵:** 전체 건물과 현재 관찰 지점의 위치를 함께 표시하였다.

### 5.2 수정 전후 비교

|---|---|

| 상세 화면에서 전체 위치 관계를 확인하기 어려움 | 미니맵에 전체 건물과 현재 위치 표시 |
| 전체 위치 확인을 위해 전체 보기로 복귀해야 함 | 상세 관찰 중에도 전체 위치 확인 가능 |

### 5.3 검증 결과 및 남은 한계

P5를 선택했을 때 명판 강조 테두리와 미니맵의 위치 마커가 정상적으로 표시되었다. 다른 지점을 선택하면 강조 대상과 위치 마커가 함께 변경되었으며, 미니맵 접기·펼치기도 정상적으로 작동하였다.

이를 통해 명판을 확대해 관찰하면서도 전체 시설에서 현재 장치의 위치를 확인할 수 있게 되었다.

다만 미니맵이 화면 일부를 차지하므로 관찰 영역이 줄어들 수 있으며, 좁은 화면에서는 미니맵을 접어야 하는 불편이 발생할 가능성이 있다.

## 6. Codex 활용 및 설계 판단

### 6.1 Codex 활용

Codex를 활용하여 `week4/improved`의 기존 코드를 분석하고, 관찰 지점 자동 이동 및 전면·측면 직교 비교 기능을 구현하였다.

기본 버전에서 발견한 회전 방향 제어의 어려움과 정확한 구조 비교의 문제를 전달하고, 기존 모델을 유지하면서 카메라와 UI를 개선하도록 요청하였다.

### 6.2 주요 설계 판단

초기 설계에서 관찰 지점 선택형과 4분할 다중 시점 방식을 비교하였다.

4분할 방식은 여러 방향을 동시에 관찰할 수 있다는 장점이 있지만, 화면이 작아져 명판의 가독성이 떨어질 수 있다고 판단하였다. 따라서 4분할 방식은 채택하지 않고, 관찰 지점 선택형에 전면·측면 직교 뷰만 결합하였다.

구현 후에는 선택한 장치의 위치를 더욱 명확하게 파악할 수 있도록 3D 강조 테두리와 전체 미니맵을 추가하도록 요청하였다.

### 6.3 Codex 제안 검토 및 판단

Codex를 활용하여 관찰 지점 선택 시 해당 명판으로 카메라가 자동 이동하는 기능을 구현하였다.

초기 구현 결과, 명판의 글자는 쉽게 확인할 수 있었지만 확대된 장치가 전체 건물의 어느 위치에 있는지 파악하기 어려울 수 있다고 판단하였다.

이에 자동 이동 기능은 유지하되, 선택한 명판의 강조 테두리와 전체 미니맵 기능을 추가하도록 Codex에 요청하였다.

수정 후에는 명판을 확대하여 관찰하면서도 미니맵을 통해 전체 건물에서의 위치를 확인할 수 있었다. 이를 통해 단순한 명판 가독성뿐 아니라 위치 파악까지 지원하도록 인터페이스를 보완하였다.

### 7.2 조작법

| 회전 | 드래그 | 드래그 |

전체 보기 버튼으로 초기 시점에 복귀할 수 있으며, 미니맵에서는 현재 선택한 관찰 지점의 위치를 확인할 수 있다.
