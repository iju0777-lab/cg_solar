# Week 5 — 태양 하나로 만드는 낮과 밤

## 1. 실습 1 — 단계별 조명 구현

### 1.1 실습 목적

조명이 적용되지 않은 3D 장면에 Phong 조명의 확산광(Diffuse), 환경광(Ambient), 정반사(Specular)를 단계적으로 추가하고, 거리 감쇠와 법선 행렬이 화면에 미치는 영향을 확인하였다. 또한 Point, Directional, Spot 광원을 비교하여 광원의 종류에 따른 밝기 분포의 차이를 관찰하였다.

### 1.2 단계별 조명 적용

**① 1단계 — 확산광(Diffuse)**

```glsl
vec3 diffuse = max(dot(N, L), 0.0) * uBaseColor * uLightColor;
fragColor = vec4(diffuse, 1.0);
```

표면 법선과 광원 방향의 내적을 이용하여 확산광을 계산하였다. 조명이 없을 때는 단색의 원처럼 보이던 구에 밝은 면과 어두운 면이 생기면서 입체감이 나타났다. 광원이 움직임에 따라 빛을 받는 면도 달라졌다.

![1단계 확산광](images/01.%20task1_diffuse.png)

**② 2단계 — 환경광(Ambient)**

```glsl
vec3 ambient = 0.08 * uBaseColor;
fragColor = vec4(ambient + diffuse, 1.0);
```

환경광을 추가하자 직접 빛을 받지 않는 부분에도 약한 밝기가 생겼다. `0.08`에서는 변화가 크지 않았지만, 값을 `0.4`로 높이자 어두운 부분이 훨씬 밝아졌다. 환경광이 커질수록 밝은 면과 어두운 면의 명암 대비가 상대적으로 감소하여 입체감이 약해진다는 것을 확인하였다.

![2단계 환경광](images/02.%20task1_ambient.png)

**③ 3단계 — 정반사(Specular)**

```glsl
vec3 R = reflect(-L, N);
vec3 specular = pow(max(dot(R, V), 0.0), uShininess)
                * uLightColor * 0.5;
fragColor = vec4(ambient + diffuse + specular, 1.0);
```

정반사를 추가하자 구 표면에 밝은 하이라이트가 나타났다. 확산광은 광원과 표면의 방향에 의해 결정되지만, 정반사는 카메라 방향도 영향을 미치므로 시점을 변경했을 때 하이라이트의 위치가 달라지는 것을 관찰할 수 있었다.

![3단계 정반사](images/03.%20task1_specular.png)

**④ 4단계 — 거리 감쇠(Attenuation)**

```glsl
float d = length(uLightPos - vWorldPos);
float att = 1.0 / (1.0 + 0.02 * d * d);
fragColor = vec4(ambient + (diffuse + specular) * att, 1.0);
```

거리 감쇠를 적용하자 광원에 가까운 영역은 상대적으로 밝고, 먼 영역은 더 어둡게 나타났다. 특히 바닥에서 광원과의 거리에 따른 밝기 차이를 확인할 수 있었다. 환경광은 특정 광원으로부터 전달되는 빛이 아니므로 감쇠값을 곱하지 않았다.

![4단계 거리 감쇠](images/04.%20task1_attenuation.png)

### 1.3 `max()` 제거 실험

**예측:** `max()`를 제거하면 빛의 밝기가 정상적으로 계산되지 않아 화면 전체가 검게 보일 것으로 예상하였다.

**실제 결과:** `max()`를 제거해도 구의 밝은 부분은 그대로 나타났으며, 어두운 부분 역시 검게 표시되어 기존 화면과 큰 차이가 없었다.

**원인 분석:** `dot(N, L)`이 양수인 부분에서는 확산광이 그대로 계산된다. 반면 음수인 부분의 색상값은 최종 화면 출력 과정에서 0으로 제한되므로 검게 나타난다. `max()`는 빛을 받지 않는 면의 확산광이 음수가 되지 않도록 계산 단계에서 제한하는 역할을 한다.

### 1.4 5단계 — 법선 행렬 비교

행성에 비균등 스케일 `(0.7, 2.2, 0.7)`을 적용하여 세로로 긴 타원체를 만든 후, 두 가지 법선 변환 방식을 비교하였다.

**① 모델 행렬 사용**

```glsl
vNormal = mat3(uModel) * aNormal;
```

모델 행렬을 그대로 사용하면 비균등 스케일이 적용된 물체의 법선 방향이 올바르게 변환되지 않을 수 있다.

![모델 행렬을 사용한 법선 변환](images/05.%20task1_mat3uModel.png)

**② 법선 행렬 사용**

```glsl
vNormal = uNormalMat * aNormal;
```

법선 행렬을 사용하면 모델 행렬의 역행렬을 전치한 변환을 통해 비균등 스케일에서도 법선 방향을 올바르게 계산할 수 있다.

![법선 행렬을 사용한 법선 변환](images/06.%20task1_uNormalMat.png)

**비교 결과:** 두 방식에서 타원체의 밝기 분포와 하이라이트 형태에 차이가 나타났다. 다만 장면의 광원과 달이 시간에 따라 움직이므로, 캡처 시점 차이도 결과에 영향을 미쳤을 가능성이 있다. 법선 행렬은 비균등 스케일 상황에서 정확한 조명 계산을 위해 필요하다는 것을 확인하였다.

### 1.5 6단계 — 광원 종류 비교

Point 광원은 한 위치에서 모든 방향으로 빛을 보내므로 바닥의 밝기가 위치와 거리에 따라 달라졌다. Directional 광원은 모든 표면에 같은 방향으로 빛이 들어오고 거리 감쇠를 적용하지 않아 바닥의 확산광이 균일하게 나타났다. Spot 광원은 Point 광원에 원뿔 형태의 조사 범위를 추가하여 광원 아래의 바닥에 밝은 원형 영역을 형성하였다. 안쪽 15°에서 바깥쪽 25°까지 `clamp()`를 이용해 빛의 세기를 선형으로 감소시켜 조명 경계를 부드럽게 처리하였으며, 원뿔 밖의 물체와 바닥에는 환경광만 남도록 하였다. 최종 Spot 광원은 `(3.0, 5.0, 0.0)` 위치에 고정하여 원형 조명 영역을 확인하였다.

![Directional 광원](images/07.%20task1_directional.png)

![Spot 광원](images/08.%20task1_spot.png)

### 1.6 실습 1 최종 구현

최종 `task1.html`에서는 확산광, 환경광, 정반사, 거리 감쇠를 적용하고 법선 행렬 `uNormalMat`을 사용하였다. 행성의 크기는 균등 스케일 `(1.3, 1.3, 1.3)`으로 복구하였으며, 광원 구는 자체발광 처리하였다.

최종 상태에는 아래쪽을 비추는 Spot 광원을 적용하여 바닥의 원형 조명 영역을 확인할 수 있도록 하였다.
