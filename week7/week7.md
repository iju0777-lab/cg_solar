# 7주차 과제 — 전역 조명과 Ray Tracing·Path Tracing

## 1. 실습 1 — 기본 Ray Tracing으로 일식·월식 구현

### 1.1 공전 위치와 그림자 광선

위성의 공전 위치가 **0°**일 때는 별–위성–행성 순서로 배치되어 일식이, **약 180°**일 때는 별–행성–위성 순서로 배치되어 월식이 발생한다. 그림자 광선은 표면에서 별 방향으로 광선을 보내 다른 천체가 빛을 가리는지 확인하고, 가려진 곳의 직접광을 제외하는 역할을 한다.

### 1.2 일식·월식 비교

**① 일식 — 공전 위치 0°**

그림자 광선을 켜면 위성 그림자가 행성에 나타나고, 끄면 해당 그림자가 사라진다.

## 실습 2. 렌더링 방식별 성능 비교

### 1. 측정 환경

- 기기: iPhone
- 브라우저: Safari
- 측정 방식: Local, Ray tracing, Path tracing
- 측정 단위: ms (밀리초)

### 2. 측정 결과

| 측정 조건 | Local | Ray tracing | Path tracing |
|---|---:|---:|---:|
| 640×360 / 8표본 / 반사 2회 | 1 ms | 2 ms | 5 ms |
| 960×540 / 8표본 / 반사 2회 | 1 ms | 3 ms | 19 ms |
| 1280×720 / 8표본 / 반사 2회 | 2 ms | 4 ms | 16 ms |
| 1920×1080 / 8표본 / 반사 2회 | 1 ms | 4 ms | 36 ms |
| 640×360 / 16표본 / 반사 2회 | 1 ms | 2 ms | 9 ms |
| 640×360 / 32표본 / 반사 2회 | 1 ms | 1 ms | 25 ms |
| 640×360 / 8표본 / 반사 3회 | 1 ms | 2 ms | 6 ms |
| 640×360 / 8표본 / 반사 4회 | 1 ms | 2 ms | 8 ms |
| 640×360 / 8표본 / 반사 4회 / 고급 효과 OFF | 1 ms | 1 ms | 8 ms |

※ 별도 표시가 없는 측정은 고급 효과 ON 상태이다.

### 3. 결과 분석

- **렌더링 방식:** 전반적으로 Local이 가장 빠르고 Path tracing의 처리 시간이 가장 길었다.
- **해상도:** 해상도가 높아질수록 Path tracing의 처리 시간이 대체로 증가했지만, 개별 측정값에는 변동이 있었다.
- **표본 수:** 8개에서 32개로 증가하자 Path tracing의 처리 시간이 5ms에서 25ms로 증가했다.
- **반사 횟수:** 최대 반사 횟수를 2회에서 4회로 늘리자 Path tracing의 처리 시간이 5ms에서 8ms로 증가했다.
- **고급 효과:** OFF 상태에서 Ray tracing은 2ms에서 1ms로 감소했으며, Path tracing은 8ms로 동일했다.

### 4. 결론

Local은 빠른 렌더링에 유리하고, Path tracing은 반사와 간접광을 표현하는 대신 계산 비용이 크다. 특히 Path tracing에서는 해상도와 표본 수가 성능에 큰 영향을 주었다. 다만 측정값은 기기 상태와 실행 시점에 따라 달라질 수 있다.
